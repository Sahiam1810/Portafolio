# Sahiam Valentina Esteban — Portafolio Personal

Portafolio profesional desarrollado con HTML, CSS y JavaScript. Diseño elegante en tonos crema y beige, con animaciones suaves, soporte bilingüe (ES / EN) y optimización SEO completa.

🌐 **Link:** https://sahiamdev.netlify.app/

---

## Características

- **Animación de cortina** al cargar la página — se abre con scroll, click o teclado
- **Bilingüe (ES / EN)** — cambio de idioma dinámico sin recargar la página, con persistencia en `localStorage`
- **100% Responsivo** — layouts con CSS Grid y Flexbox, adaptado a móvil, tablet y escritorio
- **Animaciones con AOS** — elementos que aparecen suavemente al hacer scroll
- **SEO optimizado** — meta tags, Open Graph, Twitter Card y datos estructurados Schema.org

## Tecnologías utilizadas

| Tecnología | Uso |
|---|---|
| HTML5 semántico | Estructura y accesibilidad |
| CSS3 (Grid + Flexbox) | Layout responsivo y diseño |
| CSS Custom Properties | Sistema de diseño con variables |
| JavaScript (Vanilla ES6+) | Interactividad, i18n, animaciones |
| [AOS](https://michalsnik.github.io/aos/) v2.3.4 | Animaciones al hacer scroll |
| [Playfair Display](https://fonts.google.com/specimen/Playfair+Display) | Tipografía display (Google Fonts) |
| [DM Sans](https://fonts.google.com/specimen/DM+Sans) | Tipografía cuerpo (Google Fonts) |

## SEO y Open Graph

El portafolio incluye:

- `<title>` y `<meta name="description">` optimizados
- Meta tags **Open Graph** para compartir en redes sociales (Facebook, WhatsApp, LinkedIn)
- **Twitter Card** tipo `summary_large_image`
- **Schema.org** con datos estructurados de tipo `Person`
- `<link rel="canonical">` para evitar contenido duplicado
